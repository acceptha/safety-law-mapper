크레인으로 중량물을 양중하는 작업 시 사업주 의무를 산업안전보건기준에 관한 규칙 기준으로 정리했습니다. 법령 매핑 도구에서 '크레인 양중 작업'과 '줄걸이·달기구 사용' 두 매핑을 조회한 결과이며, 모두 사람 검증을 거친 항목입니다(검증일 2026-08-26, 2026-10-14).

## 1. 크레인 본체·운전 관련 의무

| 조항 | 조문 제목 | 사업주 의무 요지 |
|---|---|---|
| 제133조 | 정격하중 등의 표시 | 양중기·달기구에 정격하중, 운전속도, 경고표시 등을 보기 쉬운 곳에 부착 |
| 제134조 | 방호장치의 조정 | 과부하방지장치·권과방지장치·비상정지장치·제동장치 등 방호장치가 정상 작동되도록 조정 |
| 제137조 | 해지장치의 사용 | 훅걸이용 와이어로프 등이 훅에서 벗겨지지 않도록 해지장치를 갖춘 크레인을 사용하고, 짐을 운반할 때 해지장치를 사용 |
| 제140조 | 폭풍에 의한 이탈 방지 | 순간풍속 초당 30미터 초과가 예상되면 옥외 주행 크레인의 이탈방지장치 작동 등 조치 |
| 제142조 | 타워크레인의 지지 | 타워크레인을 자립고 이상 높이로 설치할 때 벽체 지지(부득이한 경우 와이어로프 지지) |
| 제146조 | 크레인 작업 시의 조치 | 인양 하물 끌어당김 금지 등 크레인 작업 시 준수사항을 이행하고 근로자가 준수하도록 조치 |
| 제149조 | 해지장치의 사용 | 이동식 크레인으로 하물을 운반하는 경우 해지장치 사용 |

## 2. 줄걸이·달기구(와이어로프·체인·훅·샤클) 관련 의무

| 조항 | 조문 제목 | 사업주 의무 요지 |
|---|---|---|
| 제163조 | 와이어로프 등 달기구의 안전계수 | 안전계수 미달 달기구 사용 금지. 근로자 탑승 운반구 지지용 10 이상, 화물 하중 직접 지지용 5 이상, 훅·샤클·클램프·리프팅 빔 3 이상, 그 밖에 4 이상. 최대허용하중 표식이 붙은 달기구 사용 |
| 제164조 | 고리걸이 훅 등의 안전계수 | 달기 와이어로프·체인과 일체형인 훅·샤클의 안전계수는 해당 로프·체인의 안전계수 이상 |
| 제165조 | 와이어로프의 절단방법 등 | 양중작업용구 제작 시 와이어로프는 기계적 방법으로만 절단. 열 영향을 받은 와이어로프 사용 금지 |
| 제166조 | 이음매가 있는 와이어로프 등의 사용 금지 | 이음매가 있는 것, 소선 10% 이상 절단, 지름 7% 초과 감소, 꼬임·변형·부식·열손상된 와이어로프 사용 금지 |
| 제167조 | 늘어난 달기체인 등의 사용 금지 | 길이 5% 초과 신장, 링 단면지름 10% 초과 감소, 균열·심한 변형 체인 사용 금지 |
| 제168조 | 변형되어 있는 훅·샤클 등의 사용금지 등 | 변형·균열 있는 훅·샤클·클램프·링을 고리걸이용구로 사용 금지. 중량물 취급용구는 안전율 3 이상 확보, 자체 제작품은 비파괴시험 |
| 제169조 | 꼬임이 끊어진 섬유로프 등의 사용금지 | 꼬임 끊어짐, 심한 손상·부식, 2개 이상 연결, 작업높이보다 짧은 섬유로프 사용 금지 |
| 제170조 | 링 등의 구비 | 엔드리스가 아닌 와이어로프·체인은 양단에 훅·샤클·링·고리를 갖춘 것만 고리걸이용구로 사용 |
